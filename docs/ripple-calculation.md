## Ripple Calculation – リプル電流計算理論と実装
本ページでは、Maxwell で生成した 電流依存インダクタンスマップ L(I₁,I₂), M(I₁,I₂) を用いて、
磁気結合リアクトルを含む DC/DC コンバータの リプル電流・磁束・電圧波形を計算する方法をまとめます。

## 1. 目的（Purpose）
磁気結合リアクトルは、漏れ磁束を利用するため 線形インダクタンスモデルが使えません。
そのため、各時刻の電流値 (I₁, I₂) に応じて インダクタンスマップから L と M を参照しながら  
逐次的に波形を計算する必要があります。

## 2. 使用するインダクタンスマップ
Maxwell で生成した以下の 2D マップを使用します：

L1(I₁, I₂)

L2(I₁, I₂)

M(I₁, I₂)

Python 側では補間済みの関数として扱います：

コード
L1 = L1_map(I1, I2)
L2 = L2_map(I1, I2)
M  = M_map(I1, I2)

## 6. スイッチング動作のモデル化
Boost / Buck / Interleaved などの動作は、
スイッチング状態に応じて VL（リアクトル電圧） を切り替えることで再現します。

例：Boost コンバータ

ON：VL = Vin

OFF：VL = Vin − Vout

Interleaved の場合は、コイル A・B の ON/OFF をずらして計算します。

## 7. リプル電流の生成メカニズム
磁気結合リアクトルでは：

コイル A と B のリプルが互いに打ち消し合う

DC フラックスがキャンセルされる

漏れ磁束成分が電圧生成に寄与する

そのため、総リプルが小さくなり、
小型リアクトルでも高電力 DCDC が成立します。

## 9. Python 実装の流れ（Pseudo Code）
コード
for each time step:
    # 1. 現在の電流から L と M を取得
    L1 = L1_map(I1, I2)
    L2 = L2_map(I1, I2)
    M  = M_map(I1, I2)

    # 2. 磁束計算
    Phi1 = L1*I1 + M*I2
    Phi2 = L2*I2 + M*I1

    # 3. 電圧計算
    V1 = -(Phi1 - Phi1_prev) / dt
    V2 = -(Phi2 - Phi2_prev) / dt

    # 4. 電流更新
    I1 = I1 + (VL1 / L1_eff) * dt
    I2 = I2 + (VL2 / L2_eff) * dt
