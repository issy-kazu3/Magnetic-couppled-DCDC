# Maxwell モデル寸法の詳細（Model Geometry Details）
本ページでは、磁気結合リアクトルの Maxwell 3D モデルを構築する際に必要となる
コイル寸法・コア寸法・クリアランス・漏れ磁束経路などの幾何パラメータを体系的にまとめます。

Python DOE で寸法を変更しながら解析する場合にも、
このページの寸法定義が基準になります。

# 1. モデル全体構成（Overview）
Maxwell モデルは以下の 4 要素で構成されます。

-コイル（L1, L2）

-コア（中央脚・側脚・ヨーク）

-コイル間クリアランス

-漏れ磁束経路（Air Region）

モデルの精度は、これらの寸法を正しく設定できるかに依存します。

# 2. コイル寸法（Coil Geometry）
  ## 2.1 基本パラメータ
パラメータ	意味

Turn	巻き数

Cuh	コイル高さ

Cut	銅線厚み

Cuc1	コイル間クリアランス

Cur	コイル内側クリアランス

Clent	コイル中央の隙間

Clw	コア側クリアランス（幅方向）

Clh	コア側クリアランス（高さ方向）


  ## 2.2 寸法例（VBS から抽出）
コード
Turn = 32
Cuh  = 6.5
Cut  = 1.8
Cuc1 = 8.4
Cur  = 5
Clent = 4
Clw = 3.05
Clh = 3.25
  ## 2.3 巻き方向（極性）
L1 と L2 の巻き方向は 逆

下→上の電流で DC フラックスが打ち消し合う

→ Maxwell モデルでは コイルの向き（Current Direction）を必ず反転させる

# 3. コア寸法（Core Geometry）
  ## 3.1 基本パラメータ
パラメータ	意味

Icorew	コア幅

Icoreh	コア高さ

C1	コイル前後のコアとの距離

Uwplus / Uhplus	上ヨークの幅・高さ

Udepth	ヨークの奥行き

Usidew	側脚の幅


  ## 3.2 寸法例（VBS から抽出）
コード
Icorew = 32
Icoreh = 25
C1 = 3.56
Uwplus = 8.6
  ## 3.3 コア形状のポイント
中央脚の幅が磁気抵抗を決める

側脚の幅が漏れ磁束量に影響する

ヨークの厚みが飽和しやすさを決める

磁気結合リアクトルでは、
漏れ磁束を積極利用するため、側脚の寸法が特に重要です。

# 4. コイル配置（Relative Positioning）
  ## 4.1 コイル間距離
Cuc1（コイル間クリアランス）

Clent（中央の隙間）

これらが 漏れ磁束量を直接決めるため、
Maxwell モデルでは最も重要な寸法です。

  ## 4.2 コアとの距離
Clw（幅方向クリアランス）

Clh（高さ方向クリアランス）

C1（前後クリアランス）

これらは コアの飽和位置 に影響します。

# 5. 漏れ磁束領域（Air Region）
漏れ磁束を正しく計算するためには、
コイル周囲に十分な Air Region を確保する必要があります。

推奨設定
コイル外側に 最低 10〜20 mm の空間

上下方向にも十分な空間

Air Region を 1つの大きなボックスとして作成

座標系（VBS の leakix / leakiz）
VBS では漏れ磁束抽出用に座標系を定義します。

コード
dim leakix, leakiz
これにより、空間の代表点での漏れ磁束値を取得できます。

# 7. 寸法と磁気挙動の関係（重要）
  ## 7.1 コイル間距離が小さい → M が増加
ただし、巻き方向が逆なので DC フラックスはキャンセルされる。

  ## 7.2 コア側クリアランスが大きい → 漏れ磁束が増加
→ 電圧生成が増える
→ 小型リアクトルでも高電力が可能

  ## 7.3 中央脚が細い → 飽和しやすい
→ L が急激に低下
→ マップの非線形性が強くなる

# 8. Python DOE との連携
寸法パラメータは Python から VBS に渡すことができます。

例：

コード
```vbs
params = {
    "Cuc1": 8.4,
    "Clw": 3.05,
    "Icorew": 32,
}
```
これにより、寸法を変更しながら
最適な磁気結合リアクトルの設計探索（DOE）が可能になります。

# 9. まとめ
Maxwell モデルの寸法は解析精度を決める最重要要素

コイル間距離・コア寸法・クリアランスが磁気挙動を支配

漏れ磁束領域は十分に確保する

巻き方向（極性）は必ず反転させる

Python DOE と組み合わせることで設計探索が可能
