# インダクタンスマップ理論（Inductance Map Theory）
本ページでは、磁気結合リアクトルの 電流依存インダクタンスマップ L(I₁,I₂), M(I₁,I₂) を構築するための理論背景をまとめます。

磁気結合リアクトル、特に空間に流出する漏れ磁束を積極的に利用する構造を採用した場合、
従来の線形インダクタンスモデルでは正しい解析ができません。
そのため、3D FEMにて作成した、電流依存のインダクタンスマップを用いた解析が必須となります。

# 1. なぜインダクタンスマップが必要なのか
 ## 1.1 漏れ磁束が支配的なリアクトル構造
磁気結合リアクトルは、

コアの主磁路

コイル間の漏れ磁路

空間への漏れ磁束

が複雑に絡み合うため、磁束の大部分が非線形領域を通過します。

 ## 1.2 L と M が電流に強く依存する
磁気結合リアクトルでは、以下の値が電流によって大きく変化します。

自己インダクタンス L1(I₁,I₂)

自己インダクタンス L2(I₁,I₂)

相互インダクタンス M(I₁,I₂)

これらはコア材の非線形性(BHカーブ)にくわえて、

解放空間という磁気抵抗が不定の漏れ磁束の増減

を利用するため、単純な線形モデルでは扱えないのみならず、

１次元モデルの構築も不能であるという厄介さを抱えています。

# 2. インダクタンスの定義
 ## 2.1 自己インダクタンス L
コイル 1 の自己インダクタンスは以下で定義されます。

$$
L = \frac{\partial \Phi_1}{\partial I_1}
$$

コイル 2 も同様です。

 ## 2.2 相互インダクタンス M
コイル 1 の電流がコイル 2 に与える磁束は以下で定義されます。

$$
M = \frac{\partial \Phi_2}{\partial I_1}
$$

磁束の向き（極性）は ドット記法で決まります。

# 3. 電流依存性の発生メカニズム
 ## 3.1 コアの局所飽和
電流が増加すると、コアの一部が飽和し、
磁気抵抗が急増するため L が低下します。

 ## 3.2 漏れ磁束の増加
漏れ磁束は磁気抵抗が高い経路を通るため、
電流が増えるほど急激に増加します。

 ## 3.3 巻き方向による磁束キャンセル
L1 と L2 の巻き方向

両方のコイルにV1→V2の電流が流れる

→ DC 磁束が打ち消し合う

このため、M の符号や大きさが電流によって大きく変化します。

# 4. インダクタンスマップの構築方法
 ## 4.1 Maxwell で L1, L2, M を計算
Maxwell のパラメトリック解析で、
(I₁, I₂) の全組み合わせに対して L1, L2, M を計算します。

 ## 4.2 Python でマップ化（補間）
得られたデータを Python で補間し、
以下のような 2D マップを構築します。

L1(I₁,I₂)

L2(I₁,I₂)

M(I₁,I₂)

 ## 4.3 マップの性質
非線形

電流の組み合わせによって大きく変動する

# 5. マップを使った解析
 ## 5.1 リプル計算
電流波形を逐次計算する際、
各時刻の (I₁, I₂) に応じて L と M を参照します。

 ## 5.2 磁束計算
磁束は以下で求まります。

$$
\Phi = L_1 I_1 + M I_2
$$

 ## 5.3 電圧計算
電圧は以下の式で求まります。

$$
V = -\frac{d\Phi}{dt}
$$

 ## 5.4 損失計算
